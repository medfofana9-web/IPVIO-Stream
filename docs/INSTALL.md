# Install Fof TV

Fof TV runs on Fire TV, Google TV and Android TV. It is installed from a link, not from an app store.

## Fire TV
1. Settings > My Fire TV > Developer options: turn on **Install unknown apps** for **Downloader**.
   (No Developer options? Settings > My Fire TV > About: press OK on the device name 7 times.)
2. Install **Downloader** from the Amazon app store.
3. Open Downloader, enter `is.gd/getfoftv` and press Go. Install when asked.

## Google TV / Android TV
1. Install **Downloader** from the Play Store.
2. Settings > Apps > Security & restrictions > Unknown sources: allow **Downloader**.
3. Open Downloader, enter `is.gd/getfoftv`, install.

## First start
1. On **Who's watching?**, press **Sign in** and scan the code with your phone.
2. Sign in with your Fof TV email and password (the same form creates an account).
3. Pick your profile and enter its PIN (or create one). Your addons, lists and Continue watching come along.

Updates install from inside the app: when a new version is ready, Fof TV asks once.
