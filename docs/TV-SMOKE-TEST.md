# TV release checks

Run on both Fire Stick and onn 4K using the candidate APK and the same test profile. Record the build, model, outcome, and time to first picture where possible.

- Open a live game whose teams and start time can be verified. Check that a missing match shows recovery options, and that a backup source is for the same event.
- Interrupt playback briefly and reconnect. Check that it resumes without leaving the player. Open the source picker and choose a different source.
- Start a show, stop partway through, then resume from the other TV. Add and remove a My List item and confirm both changes on the other TV.
- Check 24/7 in-order start, continue, and shuffle. Verify the current episode and planned next episode, then check that an unavailable episode can be skipped.
- Search using the remote. Use Right from the keyboard to reach results, scroll, then press Back.
- Turn on subtitles during playback and confirm that the default background is transparent.
- Confirm a deliberately triggered playback failure appears in the account diagnostics. Check that incident details contain no title or stream address.

Keep the previous stable APK available until the candidate passes both devices. Record unavailable or unverified cases explicitly.
